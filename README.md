# PreconditioningSZI_2D
Input files and post-processing codes used in the paper: "Preconditioning of subduction zone initiation at passive margins by gravitational instabilities".

## Input files
Input files to run the models on FALCON. 
- parametri*.f90 contain the model parameters
- proprieta*.f90 contain the material properties
- SI_half20.wb contains the Geodynamic World Builder code to build the initial geometries of the domain
- B/C/D represent the viscous softening, PW2/PW3/PW4 represent the plastic softening, grav/forc/comb10/comb20/comb30 represent the model type (grav = gravitational, forc = forced, comb10 = combined with 10 Myr of gravitationa phase and so on). v001/v005/v01/v025/v05/v1 represent the convergence velocity, 1/2/3 represent the first 10, second 10 or third 10 Myr of the gravitational model.

Please note that SI_half20.wb builds the grid and the markers for the grav_1 and forc models, while it is not necessary for the remaining: grav_2 models start from the final grids and markers generated by the respective grav_1 models, grav_3 start from the final grids and markers generated by the respective grav_2 models. In the same way, the comb_10 models take in input the grav_1 models' outputs, the comb_20 take in input the grav_2 and the comb_30 take in input the grav_3.
